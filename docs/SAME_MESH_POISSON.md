# 显式参考 Poisson 后端与证据范围

本候选已实现的默认接口是 [原生节点 FEM](FEM_POISSON.md)：`nodalLayout='native'`、`degree=5`、`quadOrder=8`、`stride=[]`。`b890305` 冻结版本已有统一组件和有限空间/时间证据；当前求解链与周期 remesh 已通过 suite05，缩短后的 T1/T2/T3 尚未完成。`spectral` 和 `same_mesh_fd` 保留为显式选择的参考/实验后端，不能混淆为主干已部署算法。完整方法仍经 `config/init/context/rhs/run`，不另建演化入口。

原生 FEM 的全局流函数未知量与对流逐位共用 `x/y/r/theta`、物理 `X/Y` 与 shape；连续原生节点直接成元，少量六次元吸收区间余数，最外一个完整径向元采用六次。源无关的动态规划只改善几何分组的 Gauss 插值条件，不移动节点或按 PDE 误差选分组。raw `psi` 直接使用原生节点系数，速度取同一局部有限元基函数的导数。局部 Gauss 点只求积，不是独立全局未知量；源到求积点与跨 patch 的迹传递仍存在。

```matlab
opts = ipm_cr.config(struct('poissonBackend','same_mesh_fd', ...
    'fdOptions',struct('width',7,'traceWidth',7,'outerBoundary','decay')));
[s,ctx] = ipm_cr.init(opts);
```

选择谱参考用 `poissonBackend='spectral'`，其次数和审计容差属于 `solverOptions`。FD 的三个选项目前只接受上例值；不能把谱容差转换成 FD 精度资格。改变后端须新建 context/运行目录，不能用 `refresh` 将旧轨道改标另一方法。

## 三种离散的区别

| 后端 | 求解位置与数据传递 |
|---|---|
| `fem`（原生候选默认） | 系数严格位于原生复合网格，raw `psi` 无返回回插，速度为同一局部有限元导数；保留源到 Gauss 点和人工边界迹传递 |
| `spectral` | 独立 Chebyshev core 与分片 log-radius/角向谱网格，有源/返回映射和 overlap Schur |
| `same_mesh_fd` | 在实际输运节点求流函数和离散速度；仍有跨 patch 的人工边界传递 |

FD 在核心真实 x/y、环带真实 `t=log(r),theta` 上作七点局部多项式差分，解 `-psi_tt-psi_thetatheta=r²q`。非均匀 r 或 log(r) 不被当作均匀轴。墙 `psi=0`，源可非零；原点由核心处理。外弧是无源外域 DtN，不是直接置零流函数；未知物理外源的 `outerSourceTailCertified=false`。

两条分离人工 Dirichlet 边界用活动 donor 的高阶迹和 Schur 系统闭合，不把输运 ghost 条件直接当椭圆接口。两片活动重叠不被投影。源仍采用原生已微分余项＋解析背景直接求值，速度来自同一离散流函数。

FD 缓存特征变换、模态径向因子、trace 响应；包含稠密变换，不是线性复杂度多重网格。七点宽度或成功求解不自动保证非均匀轴、单边边界、重叠和速度的全局四阶。

原生 FEM 的非空 `stride` 只允许等于 `degree` 的兼容块度；旧 `gll_reference` 仅供直接组件参考，不进入含时 runtime。Green 富集时完整场在相同原生节点加回解析项。C0 流函数不保证速度全局 C0/C1；同节点也不证明 `O(N)` 或未知外源精度。

remesh 沿用核心25%正源主峰连墙区域的累积尺度变化触发：相对最后实际换网格参考，任一方向变化达到20%才重分布；首次只校准，检查间隔不强制插值。触发后复用相同 `mesh.build`、context 和 RHS，保留固定参考密度与有界节点移动。活动七点高阶转移后求一次 fresh 完整 RHS，直接继续；没有精度触发、候选验收、拒绝或回滚。资源归统一外部监督；旧 Green/组件结果仍按其冻结源码解释。

## 验收范围

FD 审计的 `accepted` 约束原离散分量后向误差 `<1e-10` 和人工 trace `<1e-9`；未执行完整审计的轻量调用为 `NaN`。`overlapValueMismatch/overlapVelocityMismatch` 另报，强残差/法向通量未独立获得时保持不可用。FD、谱和 FEM 的接受含义不能相互冒用。

`test_same_mesh_poisson` 保留 uniform/sinh、非均匀径向、非零墙源及调和外域的制造解、active/ghost/full 和离网格重叠误差、解析偏移、后端身份与四字时钟恢复。默认检查现在验证 FEM；谱比较显式选择。两层阶数门是严重降阶回归，不是连续阶数证明。

## 原配置下的历史测量

2026-11-01 同一 L48、R=8、原生源、单线程 MATLAB R2026a 的暖 kernel 对照如下，排除构建与离网格空间审计：

| 制造解 | FD active 速度误差 | 谱 active 速度误差 | FD / 谱 kernel |
|---|---:|---:|---:|
| dipole | `3.90e-6` | `2.08e-7` | `7.049 / 4.621 ms` |
| quadrupole | `6.25e-6` | `1.49e-6` | `6.639 / 3.611 ms` |

这组 FD 较慢；其 ghost 速度误差约 `1.11e-4 / 1.43e-4`，不能将 active 误差说成完整数组精度。以上并非当前 P5 或完整含时程序的等精度计时。

历史 FD/谱固定 sinh 中网格 `129×241 + 549×193` 的 `0→10τ` 对照分别耗时约 `2040.6 / 1316.2 s`，均 2462 步、无重试、最大阶段 CFL 约 `.2854`，未执行自适应 remesh；两轨道相近不提供连续真误差。

历史 FD `0→400τ` 使用核心 `33×61`、环带 `141×49`，共 8412 活动点，20886 接受步、无重试、最大阶段 CFL `.286709`。末态区域残差及三窗 W/q 变化通过，但原生 F 窗口变化仍未通过；冷重建端点 F/Q 最大差 `1.42e-13 / 7.13e-16` 不补齐该缺项。这一旧网格不是当前 `65×121 + 275×97` 的精确半密度粗网格，不计入新主干 T3。

非零外墙角源的有限盘截止会引入 Green 角奇性；FD 的小代数残差不能证明该处高阶速度。当前原生 FEM 已有非零墙角速度原门通过和默认 P5 共同查询有限对筛查，精确范围见 [FEM](FEM_POISSON.md)；这不替其他后端提供资格，也不证明速度 C1、`O(N)` 或未知物理源尾。旧多门版本 T1/T3 分别正常停在约 `τ=1.2878 / 23.297`；T3 为 3680 步、旧往返门拒绝 9 次。它们不能计作新简化 remesh 的通过，T1/T2/T3 仍未完成。

旧独立 GLL/P5 外墙角约 `2.6` 阶的预登记门失败、旧 Q4 Green 富集与 FD 结果均只解释其原配置。历史原始报告保留在 [VALIDATION](VALIDATION.md)、原提交及各自本地结果目录，不删除或改标为新候选通过。
