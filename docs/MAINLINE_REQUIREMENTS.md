# ipm_cr 主干交付与验收契约

日期：2026-11-02。本文记录用户要求的主干能力与验收条件，是主干后续开发、默认配置和发布评审的唯一需求索引。`AGENTS.md` 引用本契约；[架构](ARCHITECTURE.md)描述实际实现，[验收记录](VALIDATION.md)保存已经执行的证据。本文的“必须”表示交付要求，不表示当前版本已经满足；独立测试验收与生产数值计算严格分离。

## 0. 测试与正式实验严格分离

用户明确要求完整求解器不带安全机制，正式实验不设置精度门槛；误差、阶数、稳定性及数学不变量由独立测试提前验证。正式数值主链只执行已声明的方法，不按诊断误差拒绝状态、回退、重试或切换备用算法，不设置最小步长保护；CFL仅参与初始区间公式，不参与数值态验收。被动诊断可以保存，但不能决定是否继续。不得以关闭默认开关或重命名的方式保留这些机制。

remesh由核心区域相对最后一次实际换网格参考的累积形态变化触发，不得按固定τ间隔强制插值。几何变化阈值是网格适配算法的一部分，不是正式实验的数值精度门槛；删除精度安全机制不意味着删除几何触发条件。触发后作非均匀节点重分布、高阶活动点转移，重建context并计算一次完整RHS，直接继续；不含误差验收、armed状态、回退或回滚。原始参考、尺度及四字时钟由算法数据流保持，在测试中核验。

用户随后已明确恢复计算，并将三段演化时长减半；本轮为中网格 `0→5τ`、`390→395τ` 和精确半密度粗网格 `0→200τ`，主要考察与已有实验数据的复现能力。短组件/制造解测试与正式演化仍严格分开；已完成的静态 Green 审计不重复执行。

## 1. 交付范围

主干应提供一套由根目录 `main.m` 调用的、可复现的 `src/+ipm_cr` 含时求解器，具备核心内部非均匀加密、符合半平面奇异奇对称结构的外边界、高精度低复杂度有限元 Poisson、高精度稳定对流、自适应 remesh 和可靠数据存储。最终部署默认应实际启用交付能力，不能仅在研究分支提供未启用选项。

独立稳态不动点、旧 native steady-Q、旧 Cartesian/polar 算法以及实验 FD/FEM 各自保留来源、适用范围和失败记录。它们的结果不自动成为主干资格。

## 2. 网格与核心非均匀加密

- 核心内部的真实物理节点必须非均匀，可控制核心尺度、最小步长及向外过渡，并在实际中网格默认中启用。仅改变显示坐标、加密 Poisson 内部节点或重新分配外环带不满足本项。
- 差分、有限元几何、重构、墙与重叠传递、物理积分以及 CFL 必须使用实际节点和度量。网格须通过原点、墙、活动 donor 覆盖及连接质量检查。
- 粗网格须从现有非均匀中网格的真实物理轴逐轴取 `1:2:end`，即 `x/y/r/theta` 均为精确子序列；保留物理域、映射形状和核心/环带的相对分辨率规则。只把构造器点数减半但生成不同径向坐标，不满足“同一网格密度减半”。
- 粗化后重新构造微分算子、度量、三层 ghost、活动掩码、donor/交换与采样计划及几何身份。端点与 ghost 约定须显式记录；固定 ghost 层数可能改变活动边界的物理位置，须检查真实活动重叠及 donor 覆盖，不能直接沿用旧掩码或缓存。
- 一维区间密度减半意味着二维点数约为四分之一。若某方向区间数不可整除，应先设计可成对生成的中网格，而不是任意舍入并另调粗网格。

## 3. x_2 奇异奇对称、外边界与 Green 核查

在上半平面求解 `-Delta psi=q`，并由同一个流函数求 `u=(-psi_Y,psi_X)`。墙上取 `psi=0`，对应不可穿透条件 `u_2=0`；允许 `rho` 及 `q=rho_X` 具有非零的上侧墙极限。

跨 `x_2=0` 的奇延拓可以具有跳跃，不得为了套用光滑奇函数模板而清零一侧墙源，或忽略由源、墙和外圆截止共同产生的奇异项。墙端角点、墙附近与外弧都属于独立精度检查区域。

令 `Phi` 为与上述 Poisson 正负号一致的全平面基本解，`y*=(y_1,-y_2)`，反射对称半平面核为 `G_H(x,y)=Phi(x-y)-Phi(x-y*)`。外边界值、流函数和速度须与这一核的独立积分结果相符；参考积分须独立于被测有限元离散，并核查自身求积收敛。

Green 比较必须使用同一个完整源、背景分解、物理尺度、积分区域和域外模型。有限源圆盘外置零、无源外域 DtN、解析源尾或其他尾部模型须分别声明。与“同一截断模型”的 Green 结果相符，不能被表述为未知物理外源已无误差；域外源尾与外半径敏感性须另行量测。不得静默截断、清零源或拟合边界值来改善误差。

Poisson 外边界和对流外边界分别闭合。对流采用声明的多项式外延；实际入流及外延影响作为被动诊断和独立测试量，不能把内部外推称为已知物理入流真值。正式求解不据入流诊断拒绝计算。

## 4. 高精度、低复杂度有限元 Poisson

- **Poisson 与对流的主要内部节点必须完全相同。** 主体流函数未知量直接位于对流的 core `x/y` 与 polar `r/theta` 原生节点，主要节点坐标须逐位一致；仅共享物理域、映射或加密几何而在内部另布 GLL/Chebyshev 求解网格，不满足本项。用户允许物理边界和人工 trace 上存在明确的低维节点差异；若采用，须单独列出位置、自由度数量、耦合及成本，并验证边界精度、守恒/一致性和对主体场的影响，不能把内部另一套求解网格称为边界差异。Gauss 点仅作单元内求积，不构成第二套全局未知量或演化网格。流函数与速度仍来自同一有限元场；验收逐位核对主要节点，分别审计边界例外。当前候选选择全部节点共用，是该要求的一种更严格实现。
- 主干部署目标是有限元 Poisson，而非将独立谱后端或同节点有限差分重新命名为有限元。可保留参考后端，但选择必须显式，输出须记录真实后端。
- 优先四至五阶空间精度；流函数与速度分别量测，不能把 Q4 等多项式次数当作完整求解器的实测阶数。必须覆盖实际非均匀核心、环带、活动重叠、ghost、离网格点、墙、外弧及非零墙源角点。
- 速度须来自同一有限元流函数的一致求导；解析 Green 奇异项或富集部分如被使用，须纳入完整源、解、边界和误差审计，不得通过单独拟合速度掩盖误差。
- 流函数、速度及速度导数的连续性和精度分别检查。`C0` 流函数不自动给出全局连续或可微的速度；单元面取平均值也不能消除两侧极限的跳跃。需要量测单元面、重叠及边界附近的速度跳跃与其输运影响。源截止导致真导数奇异时，应分开角点与固定穿孔区域，不能宣称有限的全域导数最大范数或沿用速度的阶数。
- 低复杂度与高效率是交付条件。以近线性的逐次求解成本和存储为优化目标，分别报告构建/预处理、暖 Poisson、完整 RHS、接受步、remesh 重建、输出成本和峰值内存。用多个规模的实际测量说明随自由度的增长；全局稠密响应、特征变换或缓存的代价也必须计入，不能仅凭稀疏装配、缓存或分离变量声称 `O(N)`。
- 性能比较固定问题、误差目标、硬件、线程、CFL、输出频率和计时边界。仅能证明候选较快或达到名义阶数时，须保留其余未满足项。
- 原离散后向误差、边界/trace 一致性、重叠值与速度误差、独立 Green 真误差分别报告；小代数残差不替代连续精度。

## 5. 高精度稳定对流与时间推进

空间离散优先四至五阶中心格式。该偏好以完整离散稳定为前提；需要的耗散、滤波、限幅或其他稳定化须说明其数学作用、参数和精度影响，不能隐式降阶。若最终采用其他高阶形式，应记录稳定性或精度方面的依据与偏好尚未满足的原因。

2026-11-03 用户明确选定本次 GitHub 公开版本默认使用非均匀中网格和 `linear5` 五阶迎风，平滑速度系数 `.1`；`central4` 保留为显式参考选项。默认组合须由 `main`、`config`、case 与示例一致解析；接口及时间精度采用新默认独立验证，不继承旧中心格式的资格。源码公开不等同整套主干验收或 NAS 集成完成。

完整方案的独立测试共同检查非均匀度量、单侧墙闭合、外边界、重叠传递与时间推进。生产初始区间由当前 RHS 速率按 CFL 公式给出；原自然三次样条 IPC 的普通单峰跨相邻节点时，以固定四次弦截计算构造分段积分时间网格。该数学分段不设误差验收门、括根备用法或折半保护；不连续的全局极大值分支交换直接按原选峰公式演化。全部活动点、RK 阶段和新末态的实际速率可被动记录，不触发阶段拒绝、缩步重试或回滚。场、尺度、规范和完整物理时钟在同一阶段一致。

分别验证空间与时间误差、稳定性、峰值规范及非零背景相消；至少报告完整 `W/q/F/Q`、物理速度、去平移速度和 I/P/C 相关量。四至五阶要求须注明光滑性和被分辨条件，不能宣称任意未分辨奇异剖面均有该阶数。

不得通过放宽独立测试阈值、重设规范或覆盖另一片活动值来换取轨道通过。运行期数值保护已按最新要求删除；样条节点的分段 RK4 与规范更新须独立验证。浮点 ULP 仅识别同一节点坐标，不投影峰值或主态。若需要改变规范或连接算法，先写明数学变更并单独验证。

## 6. 自适应 remesh

沿用旧报告的形态触发定义：取全活动区正 `q` 峰值的 `25%` 超水平集，定位包含主峰且连墙的连通分量，以其横向最大绝对范围与纵向最大范围为核心区域尺度。与最后一次实际 remesh 后保存的尺度比较，任一方向累积相对变化达到 `20%` 才触发插值。每次检查不得重置该累积参考；实际 remesh 后才更新。首次调用仅建立形态参考，不强制插值。`checkEveryTau=.5` 是最大检测间隔；沿用旧形态变化率与阈值余量的观测调度，在 `.005… .5τ` 内安排下一次检查，不改变积分步长，也不触发无条件 remesh。平稳形状即使运行很久也不应反复插值。

此前实现自行加入、并误写入本契约的 `intervalTau=2` 周期插值规则并非用户要求，现明确撤销。历史周期实验保留为不符合触发要求的实验记录，不作为原设置复现通过证据。触发后仍在固定原始参考核心上，根据当前解构造非均匀密度目标并作有界节点移动，保留现有高阶转移。

换网格是在同一物理时刻的表示变换。活动 donor 七点高阶转移主态与余项，保留原始 I/P/C 参考、尺度、密度原点、背景和全部补偿时钟字；复用 `mesh.build` 与现有 context 路径重建几何相关计划，计算一次 fresh 完整 RHS 后直接继续。不能重新初始化原问题、改变物理时间或用新网格重设规范参考。

生产流程不含精度触发阈值、armed 状态、候选验收、拒绝、回滚或内部资源机制。转移误差、高阶精度、重复调整、实际 remesh 和冷恢复由独立测试验证。数学运算或结构输入错误如实暴露，不捕获后改用旧态或备用算法；资源预算由外部监督器管理。

起始中、粗网格严格遵守第 2 节的逐轴子序列规则；自适应阶段沿用同一物理监测与网格构造规则，以统一的各方向密度倍率 `1` 与 `1/2` 区分。记录每次实际节点、映射与触发时刻，不能暗示独立自适应轨道始终节点嵌套；受控空间阶试验须另行规定成对几何、逐轴粗化和可比较的触发序列。
