当前 `codex/mainline-adaptive-20261102` 默认后端为 `fem`，尚未部署 NAS 主干。配置由 `ipm_cr.config` 和 `poisson.fem.options` 解析：

已实现的默认布局为 `nodalLayout='native'`：全局流函数未知量严格使用输运的原生 `x/y/r/theta`、物理 `X/Y` 与同 shape 数组；不仅共享 patch 外框。该布局在 `b890305` 冻结版本已有组件及有限空间/时间证据；当前还移除了运行期数值验收与备用路径，并固定每次线性解作一次弱残差修正；样条分段 RK4 及周期 remesh 已通过 `compute_only_release_05` 请求检查，缩短后的三段复现仍未完成。源和物理模型不变，旧证据不自动认证新版本。

```matlab
opts = ipm_cr.config(struct('poissonBackend','fem', ...
    'femOptions',struct('nodalLayout','native','degree',5,'quadOrder',8,'stride',[], ...
        'linearSolver','sparse_direct','cornerCorrection',true)));
[s,ctx] = ipm_cr.init(opts);
```

## 几何、弱式与缓存

核心按物理 x/y、环带按 log-radius/角度组装 `-Delta psi=q` 的张量 Galerkin 弱式，流函数系数的物理位置始终为原生节点。默认 `degree=5`、`quadOrder=8`、`stride=[]`；连续原生节点组成五次 C0 Lagrange 元，共享端点，少量六次元吸收区间余数。最外一个完整径向元固定采用六次；若原区间数恰可被五整除，则重新分组这些区间，以容纳该策略，仍不新增或移动节点。实际各轴次数与外边界次数策略随诊断记录，不能把混合五/六次元称为处处相同次数。

元素分组使用只依赖原生坐标的动态规划，最小化 Gauss 基函数取值矩阵的最坏 Lebesgue 因子；相同目标下优先较均匀的次数分布。该 conditioning 不读取源、解或 PDE 误差，既不挑误差较小的点，也不修补已求得的速度。Gauss 点始终只求积，全部流函数自由度仍是原生点。

原生布局的非空 `stride` 仅允许等于 `degree`，作为兼容块度，不允许它重新采样出另一套全局未知量。`gll_reference` 只保留在直接组件 solver 中作显式参考，含时 `config/context` 不接受。

raw FEM 的 `psi` 数组直接使用同 shape 节点系数，无需从独立求解网格回插；速度来自同一局部流函数基函数的解析导数，不单独拟合。Gauss8 点只负责局部非集总弱式积分：原生余项源仍由唯一活动 owner 重构到求积点，解析背景源在求积点直接求值，人工 patch 边界仍需迹传递。因此同节点不等于所有源/接口传递均被取消。

默认缓存两 patch 的稀疏 Cholesky、齐次 trace 响应和小型 Schur 系统。逐次求解复用因子，不作稠密模态变换；`linearSolver='modal'` 是明确选择的代数参考。稀疏因子填充、DtN 构建特征分解、trace 响应、Green 缓存及 remesh 重建都有成本；需量测误差、setup/solve/完整 RHS 与内存随规模增长，尚无 `O(N)` 复杂度证明。

remesh 沿用核心25%正源主峰连墙区域的累积尺度变化触发：相对最后实际换网格参考，任一方向变化达到20%才重分布；首次只校准，检查间隔不强制插值。触发后复用相同 `mesh.build`、context 和 RHS，保留固定参考密度与有界节点移动。活动七点高阶转移后重建一次 context，求一次 fresh 完整 RHS，直接继续；无精度触发、候选验收、拒绝或回滚。资源由统一外部监督器管理。独立 Green 精度研究继续保留其来源，不在每次 remesh 重算或借此认证新轨道。

## 半平面与外域模型

墙上 `psi=0`、`u2=0`，允许非零一侧墙源；密度/源的 x_2 奇延拓可以有跳跃，不强迫其跨墙光滑。含时接口只接受显式 `finite_source_disk_zero_exterior`：给定源圆盘外为零，并以外域 DtN 闭合。未知物理外源的 `outerSourceTailCertified=false`。

非零源在外圆与墙交点产生截止角奇异。对 `declared_compact_source`，富集写作 `q=qP+(q-qP)`、`psi=Green(qP)+FEM(q-qP)`：二十系数多项式匹配两角总阶三源 jets，同一解析有限半盘 Green 场加到两 patch 的原生节点、trace 与审计点，不清除墙源。此时原生系数表示 FEM 余项，完整 `psi/u` 加回相同位置的解析场，仍无另一套全局未知量。

富集只适用该 compact-source 模型。已知完整平滑外源/Green Dirichlet 问题旁路有限盘富集；否则可能人为引入奇异余项。直接组件 solver 可接受有明确来源的 Green Dirichlet 或外域数据，含时适配器不据此推断未知外源。

独立参考须使用反射核 `G_H(x,y)=Phi(x-y)-Phi(x-y*)`、相同完整源、尺度、盘半径与域外模型，并检查参考求积收敛。与同一截断模型相符不等于物理尾误差已经消失。

## 连续性与诊断含义

C0 流函数保证单元面值连续，不自动保证速度 C0/C1。接口返回两侧解析导数的平均值只是取值约定，不消除速度的单侧跳跃。速度、其导数、单元面和人工重叠的误差必须分别量测；截止角真导数可能奇异，需区分角点与固定穿孔区域。

每次稀疏或模态 patch 求解固定作一次原弱残差修正；不按残差选择迭代次数或回退。`solverCompleted` 只表示计算返回，`accuracyAssessed=false`；弱行、trace、边界、重叠及源重构量仅为被动诊断。独立测试保留原弱行 `<1e-10`、trace/边界 `<1e-9` 等阈值；小代数残差不替代 Green 连续真误差，没有独立强残差时保持不可用。

## 独立测试与历史证据

`b890305` 冻结版本的本地统一验收 `native_release_01` 中，31 项请求检查均满足，耗时 `237.63 s`，源码及测试输入身份守卫保持不变；新周期 remesh 已在 suite05 中验证，但三段复现尚未完成。旧 radial 测量的完整空间资格仍为 false；它没有因统一检查执行完成而变成通过。以下为当前原生布局的有限验证：

| 同一测试的角点速度 | 观测阶 `4.0242–4.1302` | 只认证该独立 Green 参考与所测源族 |
